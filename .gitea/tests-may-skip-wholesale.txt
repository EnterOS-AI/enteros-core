# Packages whose tests may legitimately skip WHOLESALE under `CI / Platform
# (Go)`'s `go test ./...`, checked by .gitea/scripts/assert-tests-executed.py.
#
# Being on this list is not an exemption from testing. It is a claim that the
# package's tests execute for real SOMEWHERE ELSE, and the reason must say
# where. If a reader cannot follow the reason to a lane that actually runs the
# package, the entry is wrong.
#
# AND THE LANE MUST BE ABLE TO PROVE IT RAN. This is the part that is easy to
# get wrong, and it was wrong here first: naming a lane whose only verdict is
# `go test`'s exit code moves the vacuous pass rather than closing it. A
# dropped or mistyped env var makes the test skip, that lane exits 0 green,
# this file waves the package through -- and it now executes NOWHERE with
# every gate green. Before adding an entry, open the lane and confirm it
# asserts a non-zero count of executed tests (the `--- PASS:` idiom in
# concierge-creates-workspace-hermetic.yml). An exemption is only ever as
# good as the assertion in the lane it points at.
#
# Format:   <go import path>  # why it skips here, and where it DOES execute
#
# Both directions are enforced:
#   * a package that skips wholesale and is NOT listed here fails the gate;
#   * an entry that is no longer all-skip (or names a package that no longer
#     exists) also fails the gate, so the list cannot rot into a rubber stamp.
#     If you get that failure, DELETE the line — do not "fix" it.
